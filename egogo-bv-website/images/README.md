# Foto's / Photos

Plaats hier de eigen projectfoto's met exact deze bestandsnamen — de website
gebruikt ze automatisch. Ontbreekt een foto, dan valt de site terug op een
online stockfoto.

| Bestandsnaam | Foto |
|---|---|
| `zonnepanelen.jpg` | SmartFlower / zonnepanelen-installatie (ook gebruikt als hero-achtergrond) |
| `laadpalen.jpg` | Laadpalen op de parking |
| `elektriciteitswerken.jpg` | Verdeelbord / elektrische kast |
| `warmtepomp.jpg` | Buitenunit op plat dak (sectie "Over ons") |
| `thuisbatterij.jpg` | (optioneel) thuisbatterij-installatie |
| `sanitair.jpg` | (optioneel) sanitaire werken |
| `keuring.jpg` | (optioneel) keuring / inspectie |

Tip: comprimeer foto's tot ± 1600 px breed (bv. via tinypng.com) voor een
snelle laadtijd.
